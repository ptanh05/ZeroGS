# CVPR 2027 Draft Package

This directory is a new, anonymous review-draft package. The pre-existing files directly under `submission/` were not overwritten.

## Build

Compile `main.tex` with a LaTeX engine compatible with the official CVPR 2027 author kit. The checked PDF was generated with Tectonic 0.17.0.

## Contents

- `main.tex`, `preamble.tex`, `sections/` — manuscript source
- `references.bib` — verified bibliography
- `figures/` — vector PDF and 320-DPI PNG figures
- `supplementary/` — supplementary source and compiled PDF
- `main.pdf` — checked anonymous review draft

The evidence ledgers, validation scripts, reviewer simulation, and writing reports remain in `paper/final_paper/` and are intentionally excluded from this submission-facing package.
